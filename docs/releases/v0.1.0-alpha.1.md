# CleanMyMic v0.1.0-alpha.1 — First preview

CleanMyMic is a Mac menu bar app for local microphone cleanup using Core ML. This is an **experimental preview** for Apple Silicon and macOS 15 or later. It is not ready for dependable everyday calls.

## Included

- Swift menu bar app with a native panel: one on/off switch at the top right (off passes your original voice through the same virtual microphone), automatic microphone selection with an override, and **Hear yourself**, which plays your mic to your headphones so you can compare **Original** and **Cleaned** before a call. **Settings…** opens a window with cleanup strength and the model. One model: CleanMyMic Base.
- Automatic macOS input routing and on-demand capture: **Ready** until an app uses the virtual microphone, **In use** during capture, and the physical mic is released when the last app stops. This applies whether CleanMyMic is switched on or off. Virtual-microphone build scripts are included.
- Python model export and evaluation tools and checkpoint-specific benchmark evidence.
- Build checks and an agent-assisted setup guide.
- One signed, notarized installer with the app, virtual microphone, and Base model; driver source, notices, build/model hashes, and a removal script are included. No separate model download is needed to run it.
- Three [10-second real-world audio comparisons](../audio/README.md): CleanMyMic Base, DeepFilterNet3, and Krisp VI 2.5 HD on office, call-center, and car recordings selected for stronger background noise. Sources and credits accompany the audio.

## Known limitations

- **Unresolved voice loss:** intermittent loss of the caller's voice has been reported in a café call using AirPods Pro and Google Meet while background audio/music remained audible. The cause is not isolated; use a physical mic directly for important calls. [Diagnostic steps](../../INSTALL.md#voice-cuts-out).
- CleanMyMic Base's published scores are small development samples. They do not establish superiority over other Mac apps or predict every microphone and room.
- Speech preservation and phone background-voice suppression still need work.
- Live-call latency, battery use, long-session reliability, and blind listening preference have not been established by the published checks.
- Clean-Mac install, upgrade, and removal tests have not been completed.

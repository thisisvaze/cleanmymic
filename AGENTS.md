# Repository workflow

- Work on a feature branch and open or update a draft pull request for review. Do not commit or push directly to `main`.
- Leave merging to the owner. Do not merge a pull request, enable auto-merge, or enqueue a merge unless the owner explicitly authorizes that pull request in the conversation.
- Run the checks appropriate to the change and report what was not verified.
- Keep benchmark claims tied to the measured checkpoint, dataset, and method. Do not describe older results as scores for the current model or claim superiority unsupported by the results.

These are agent instructions, not GitHub-enforced branch protection.

For requests to install CleanMyMic, read [INSTALL.md](INSTALL.md) first. It states which release artifacts exist and how to verify setup; a successful source build does not mean the app is installed and working.

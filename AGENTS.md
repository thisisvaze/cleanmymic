# Repository workflow

- Work on a feature branch and open or update a draft pull request for review. Do not commit or push directly to `main`.
- Leave merging to the owner. Do not merge a pull request, enable auto-merge, or enqueue a merge unless the owner explicitly authorizes it.
- Run the checks appropriate to the change and report what was not verified.

For requests to install CleanMyMic, read [INSTALL.md](INSTALL.md) first; a successful source build does not mean the app and virtual microphone driver are installed and working.
